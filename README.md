### 💫 About Me

I build **computer-vision and real-time systems** — from capture and GPU inference to native desktop apps and the cloud services that ship them.

- 🎯 **Computer Vision** — YOLO training, labeling and model conversion (PyTorch → ONNX → TensorRT / DirectML)
- ⚡ **Real-Time & Low-Latency** — DXGI / OBS / NDI / GStreamer capture pipelines and hardware I/O
- 🛠️ **Native Desktop** — C++17 + Qt 6 on Windows, Rust + Tauri 2 for lightweight apps
- 📈 **Data & Research** — Rust services on PostgreSQL, Discord bots and MCP integrations
- 🌐 **Web & Cloud** — TypeScript + React front-ends, Cloudflare Workers / R2 delivery
