### 💫 About Me

I build **computer-vision and real-time tools** — from training and converting YOLO models to measuring end-to-end capture latency down to the frame.

- 🎯 **Computer Vision** — YOLO training, labeling and model conversion (PyTorch → ONNX → TensorRT)
- ⚡ **Real-Time & Low-Latency** — capture cards, OBS / NDI / GStreamer pipelines, hardware input
- 🛠️ **Native Performance** — C++ / CUDA / OpenGL for the hot path, C# for desktop tools
- 🌐 **Web & Cloud** — TypeScript + React front-ends deployed on Cloudflare
